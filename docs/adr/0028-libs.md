# 0028. Legacy libs client

- Status: Accepted
- Date: 2026-11-21

## Context

The legacy `packages/libs` client: contract call ordering, Solana account layouts, signature formats, relay behaviour and node selection. These records were moved out of code comments by the comment purge ([0001](0001-no-code-comments.md)). Each links to where the comment sat at `b3133cffff`.
